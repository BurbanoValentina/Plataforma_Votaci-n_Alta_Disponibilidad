🏗️ Arquitectura y Gobernanza del Sistema

Apache Kafka Broker:

Topics compactados: eligible_voters (KTable), raw_votes (Deduplicación por key user_id), security_alerts.

RabbitMQ Bus:

Exchanges reactivos: Fanout live_results_global y Topic live_results_regional con routing keys results.<region>.

PostgreSQL Forense:

Tablas inmutables: audit_votes y security_incidents (Patrón State: Normal, Sospechosa, Bloqueada).

Gobernanza SO & POO:

Límites estrictos de hardware (cgroups CPU/RAM), JVM MaxRAMPercentage=75%, Records Java 17+ inmutables, DIP y TDD.
